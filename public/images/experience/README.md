# Logos de empresas — Experiencia laboral

Coloca aquí el logo de cada empresa, con el nombre de la empresa en
minúsculas y sin tocar código:

- `michelin.png`
- `synersight.webp`
- `cognizant.png`

Se usa automáticamente en la sección Experiencia (se busca primero `.png`
y luego `.webp`). Si la empresa no tiene archivo, se muestra su inicial.
