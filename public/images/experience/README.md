# Logos de empresas — Experiencia laboral

Coloca aqui el logo de cada empresa, con el nombre de la empresa en
minusculas y sin tocar codigo:

- `michelin.png`
- `synersight.webp`
- `cognizant.png`

Se usa automaticamente en la seccion Experiencia (se busca primero `.png`
y luego `.webp`). Si la empresa no tiene archivo, se muestra su inicial.
