# Mario Muñoz — Portfolio

Portfolio personal e interactivo desarrollado como una experiencia web, no simplemente como un CV.

Diseñado alrededor de una estética inspirada en **Persona 5**, el proyecto reúne mi perfil, formación, experiencia, proyectos y habilidades dentro de una interfaz que busca mezclar desarrollo, diseño e interacción.

La idea es sencilla: **mostrar quién soy y qué sé hacer construyendo algo que también refleje cómo me gusta crear.**

## Tecnologías

- React
- TypeScript
- Vite
- Tailwind CSS
- HTML / CSS
- JavaScript

## Contenido

- **Perfil** — información personal y trayectoria.
- **Inventario** — proyectos y trabajos desarrollados.
- **Progreso** — experiencia y evolución profesional.
- **Habilidades** — tecnologías y herramientas con las que trabajo.

El portfolio está pensado como un proyecto vivo, por lo que tanto su contenido como su diseño pueden seguir evolucionando.
